## О проекте

Цель работы - оценить связь корпоративных новостей с движением котировок ценных бумаг, а также построить ML-модели для автоматического определения значимости новости и направления её влияния на цену.

## Данные и разметка

**Источники:** новости получены с портала [e-disclosure.ru](https://www.e-disclosure.ru/), исторические котировки - с Московской биржи (MOEX).
**Эмитенты:** Сбербанк, Лукойл, Магнит, НЛМК, Группа Позитив.
**Выборка:** для обучения классификаторов размечено 1000 новостей. 

В данных присутствует сильный дисбаланс классов:

| Класс | Интерпретация | Доля в выборке |
| :---: | :--- | :---: |
| **0** | Несущественная новость | ~ 84% |
| **1** | Значимая новость (цена растёт) | ~ 14% |
| **-1** | Значимая новость (цена падает) | ~ 2% |

## Решаемые задачи

1. **Классификация:** отнесение текста новости к одному из трех классов (`0`, `1`, `-1`). Оценка качества производилась по метрике F1-score.
2. **Регрессия:** прогнозирование абсолютного значения лог-доходности акции (в окне ±3 торговых дня) на основе текста новости.

## Стек

Python, pandas, scikit-learn, CatBoost, TF-IDF, ruBERT, Selenium.

## Задача классификации
Из-за сильного дисбаланса прямой мультиклассовый подход (CatBoost на TF-IDF) показал плохую полноту на редком классе `-1` (несмотря на общую accuracy ≈ 0.91). 

Оптимальным решением стала двухэтапная бинарная классификация (Random Forest + SMOTE):
Этап 1: бинарный классификатор отделяет значимые новости от несущественных.
Этап 2: второй классификатор определяет направление влияния (+1 или -1) только для значимых новостей.

| Класс | Алгоритм | Метрика F1-score |
| :---: | :--- | :---: |
| 0 | Random Forest (Этап 1) | 0.96 |
| 1 | Random Forest (Этап 2) | 0.88 |
| -1 | Random Forest (Этап 2) | 0.67 |

## Задача регрессии

Для предсказания точного значения доходности тестировался классический подход к извлечению признаков TF-IDF и подход на основе эмбеддингов.

| Подход к извлечению признаков | Модель | R² (Train) | R² (Test) |
| :--- | :--- | :---: | :---: |
| TF-IDF | Random Forest | ~ 0.84 | -0.39 |
| TF-IDF | CatBoost | > 0.80 | < 0 |
| ruBERT Embeddings | RF, LightGBM, SVM | > 0.80 | < 0 |

## Результаты

Модели регрессии не обладают обобщающей способностью на тестовой выборке. Прогнозировать точную доходность исключительно по тексту новости оказалось неэффективно. Это в свою очередь подтвердило теорию эффективного рынка о том, что вся доступная информация уже отражена в рыночных ценах. 

Задача классификации направления движения была решена с высокой точностью.
